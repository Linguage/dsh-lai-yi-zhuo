「来一桌」首次在 GitHub 公开发行，插件包名为 `dsh-lai-yi-zhuo`。安装后，DSH 侧栏与游戏大厅均显示「来一桌」。

- 棋桌提供五子棋、围棋、中国象棋和国际象棋。
- 牌桌提供掼蛋、斗地主、升级和双扣。
- 麻将桌提供基础麻将、川麻血战到底、川麻血流成河和广东推倒胡。
- 所有玩法使用本地人机陪练，提供五档难度和本机续局。

下载本页的 `dsh-lai-yi-zhuo-0.3.1.tgz`，在 DeepSeek Harness 的「插件 → 添加插件」中填写该文件的绝对路径，安装后从侧栏打开。兼容 DSH `>=0.2.0-0 <0.3.0`。

已安装旧包 `dsh-board-games` 的用户，先在同一 profile 中卸载旧包，再安装来一桌。新版本沿用原游戏地址和存档键。附件 `SHA256SUMS` 可用于核对安装包。
